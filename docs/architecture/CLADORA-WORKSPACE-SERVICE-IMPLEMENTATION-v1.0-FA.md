## بسته اول منابع و اختیار

پیش از نوشتن کد، موجودیت‌های عمومی احتمالی با نام‌های دیگر، RLS جاری، gateway، نقش‌ها و context grants بررسی شوند. property_id الزامی تجهیزات در تعریف اولیه نباید صرفاً حذف شود؛ حفظ قیود ancestry و رفتار موجود لازم است.

خروجی مرحله اول:
- نگاشت یکتای موجودیت تخصصی به مرجع عمومی؛ بدون تکرار مشخصات.
- تعلق معتبر منبع به Workspace و جلوگیری از اتصال نامجاز.
- روابط بدون چرخه و تغییر ساختار بدون گسترش پنهان اختیار.
- توسعه محدوده نقش و تفویض مرکزی همراه API و validator.
- سازگاری contextهای قدیمی و جلوگیری از fallback به نقش گسترده.
- اثر پایان binding، نقش یا اختیار grantor بر عملیات آینده.
- انتخاب صریح سیاست درخواست حساس و محل اجرای AAL2.

معیار پذیرش:
1. منبع متعلق به Workspace دیگر قابل مشاهده یا تغییر نباشد.
2. اختیار منبع A اجازه اقدام روی B ندهد.
3. deny مرتبط در کاربر چندنقشی دور زده نشود.
4. تفویض پس از لغو اختیار grantor مؤثر نباشد.
5. نگاشت دوباره همان تجهیز مرجع جدید نسازد.
6. ساخت چرخه و اتصال بین tenantها بدون قرارداد رد شود.
7. APIهای قبلی با زمینه مجاز همان نتیجه مجاز را بدهند.

| موضوع | قاعده پایه | خروجی لازم |

| اشتراک بین tenantها | حداقل تبادل از قرارداد صریح | مرز API و تأیید هر طرف |

این موارد نیازمند بررسی فنی‌اند؛ مجهول بودنشان دلیل ساخت جدول یا سامانه موازی نیست.

## اعتبارسنجی هر تغییر کد

راهنمای AGENTS.md و docs نسخه نصب‌شده Next.js پیش از تغییر کد خوانده شوند. پیش از پیاده‌سازی Supabase، changelog و docs مربوط بررسی و CLI version pin شود. migration با فرمان migration new ایجاد شود؛ نام زمان‌دار دستی جعل نشود.

هر بسته کد باید شواهد checks مرتبط، آزمون رفتار و دسترسی و در UI آزمون سرتاسری داشته باشد. آزمون متن سند یا mirror implementation جایگزین آزمون رفتار نیست. تست‌های پایه نقش و تفویض و gateway متأثر نیز اجرا شوند. داده تست از داده مشتری جدا باشد.

## مرز انتشار

مستندات این PR بدون تغییر runtime هستند. PRهای پیاده‌سازی باید schema، API، UI و آزمون لازم را در scope واضح ارائه کنند. نتیجه local یا Preview به معنی آماده بودن Production نیست. اجرای remote، merge و انتشار با scope همان مرحله و وضعیت بررسی‌های آن تعیین می‌شوند؛ این سند به‌تنهایی آن‌ها را انجام نمی‌دهد.
