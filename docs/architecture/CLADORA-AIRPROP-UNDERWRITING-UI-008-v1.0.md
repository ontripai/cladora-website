# AIRPROP native underwriting UI 008

Depends on merged contract #232 and runtime #234. Adds an explicit evaluation action to an opportunity in the selected authorized workspace; no inferred first opportunity. Separate EN/RO/FA component, including RTL, reads immutable history and the current server version before a new evaluation. The opportunity currency is fixed. Acquisition cost, annual rent and operating expenses use the strict merged contract, remain decimal strings, and are calculated only by the server. History renders exact amounts and shifts yield decimal strings to percentages without Number coercion, including signed stored results. Legacy v1 assumptions may omit currency or use lowercase; history uses the immutable result currency and never converts it to the opportunity currency. New commands always use the current opportunity currency.

Every POST is persisted before dispatch in versioned session storage scoped to context/workspace/opportunity. An uncertain result freezes the inputs and retries the identical key, expected version and normalized assumptions across remounts. Network errors, server failures, malformed/mismatched success, MFA and access denial retain the saved request. A definitive server conflict clears the rejected command but requires an explicit history refresh before a new submission. Storage failures/corrupt saved data block writes. An in-flight guard prevents simultaneous submit events.

An authority/resource change mounts a fresh state machine. Generation checks reject late POST completion; aborted GETs are checked after JSON parsing. Previous-scope pending commands remain recoverable. The parent discovery/opportunity reads also reject aborted responses. Backend native workspace gates remain authoritative; the UI does not grant access or use legacy property permissions as native authority.

Verification: actual mounted React/JSDOM tests exercise explicit parent selection, history, empty/invalid inputs, editable decimal-string commands and expected version, remount recovery/exact retries, 503/lost responses, MFA/access denial, definitive conflict and refresh, late GET/POST results, malformed success, double submits, corrupt/unavailable storage, precise large and signed legacy results and EN/RO/FA. Existing native opportunity UI regression, compiled real API/contract checks, lint, typecheck and i18n accompany the dedicated CI workflow.

Rollout is a separate step: migration 20261004074606_airprop_native_underwriting_v2.sql must exist remotely, and a bounded authorized test role must explicitly include airprop.underwriting.manage. Existing opportunity-only pilot grants do not provide that permission. No production migration, role grant, entitlement change or live-browser evaluation is performed by this UI slice. No SERVICE/Operations domain source changes.
