# CLADORA C15 observed savings evidence v1.0

This minimum runtime slice converts the accepted C14 Workspace prior-period comparison into an observed variance projection. A lower current expense total is reported as `observed_savings`; a higher total is reported separately as `observed_added_cost`. The result is arithmetic evidence, not proof that CLADORA or a particular intervention caused the change.

The RPC calls `get_workspace_cost_benchmark_v1` and therefore inherits its current AUTH-01, accounting-module, Workspace/property binding and existing-ledger scope. C15 creates no savings registry, journal, valuation model, regional dataset or mutation path. Causal attribution and asset-value claims are always withheld until separately approved evidence exists.

The bounded GET API and authenticated Financial Reports page are the real consumer. Local pgTAP/API/TypeScript checks are review evidence only and do not authorize activation, merge, remote migration, Production deployment or publication.
